# 中風居家單張產生器｜工作檔

網站上的位置：<https://chunyenwu.net/stroke-sheet/>

跟骨科的居家運動單張產生器（`exercise-sheet/`）是**兩套獨立的東西**——版面語言相近，
但資料、動作、欄位都不共用。中風的動作幾乎不與骨科重疊，硬共用只會讓兩邊互相牽制。

## 檔案在哪

**程式本體只有一份**，在 `public/stroke-sheet/`：

```
public/stroke-sheet/
  index.html   介面、渲染、列印樣式
  sheets.js    七張單張的全部內容
  og.png       分享縮圖 1200×630
```

本資料夾放**不會部署出去的工作檔**：

```
tools/stroke-sheet/
  下肢1〜4-草稿.html     七張的手寫原稿（產生器的內容即由此抽出）
  上肢A〜C-草稿.html
  步態訓練來源對照.html  六份來源對中風步態訓練說法的並排比較
  OG圖-原始檔.html       分享縮圖的原始檔
  讀我.md
```

草稿保留著，因為它們是**內容的來源與定稿紀錄**；產生器的 `sheets.js` 是從草稿抽出的資料版。
兩邊若不一致，以 `sheets.js` 為準。

## 七張的分層

功能為主軸、期別只當閘門。下肢與上肢分開，因為兩者的恢復是解離的。

| 代號 | 病人端描述 | 讀者 |
|---|---|---|
| le1 | 還沒辦法自己站起來 | 照顧者 |
| le2 | 能扶著站、能轉位到輪椅 | 照顧者 |
| le3 | 室內能走，出門要人陪 | 病人 |
| le4 | 能自己出門，但走不遠或不敢 | 病人 |
| ueA | 手完全不能動 | 照顧者 |
| ueB | 肩肘能動、手指不行 | 病人 |
| ueC | 能抓握但笨拙 | 病人 |

照顧者版（le1、ueA）的列印字級是 11pt，其餘 10.2pt——那兩張的讀者常是長者。

## 產生器的五個輸入

下肢層級、上肢層級、患側、場景（門診／住院）、輔具。輔具只在下肢 3、4 時出現，
因為前兩個層級是扶固定物，器材不影響內容。

**加分動作可勾選，主動作固定三項不可拆**——三個主動作是互相支撐的一組處方，
拿掉任何一個另外兩個就不完整。

## 安全規則（程式會自動處理）

**下肢層級 1–3 且上肢選 C 時**，「把健側手收起來」那一項會自動改成只能坐著做，
並在控制面板顯示提示。理由是那隻好手是病人平衡與自我保護的工具——
這是七張裡唯一一處正反面會互相影響的地方。

控制面板的警示**可以並列**：沒選層級、安全內容被精簡／關閉、座位限制，
三者彼此獨立，各顯示一條。（本來是 else-if 串接，結果座位限制那條會把
「安全內容關閉，連緊急送醫訊號都不印」蓋掉——偏偏那是最需要被看到的一條。）

## 改內容

全部在 `sheets.js`，語法寫在檔案開頭的註解裡。重點：

- `{患}` `{健}` 由產生器填成左／右，**步驟文字裡不要寫死「左手」**
- `%{就醫}` 這類是依場景切換的共用語句，改一次七張都會跟著改
- `{clinic:A|inpatient:B}` 是行內的場景變體
- 條目加 `dev:'walker'|'cane'|'none'` 就只在該輔具時出現

## 一份單張＝一張紙雙面

一個病人拿到的是**下肢一張紙（雙面）＋上肢一張紙（雙面）**，不是原本設想的
一張紙正反面——內容量撐不住那個設想，量過才知道。

六張是 2 頁，**下肢 3（加分動作維持預設全勾）是 3 頁**。取消任一個加分動作、
或把版面改成雙欄，就會回到 2 頁。這件事不必再靠記憶：控制面板下方會即時顯示
**「下肢 N 頁 ＋ 上肢 N 頁 ・ 共 N 張紙」**，超過 2 頁的那一張會標紅並附上怎麼縮回去。

頁數是這樣算出來的：把同一份單張放進一個離畫面的容器（`#measure`），
套上**從 `@media print` 規則複製出來、加上 `#measure` 前綴**的同一份樣式，
再依頂層區塊貪婪裝箱。列印樣式裡每個頂層區塊都是 `break-inside:avoid` 的原子單位，
所以裝箱結果就等於瀏覽器的實際分頁——**19 種組合用無頭 Chrome 對過，預估與實際完全一致**。
紙張尺寸是從 `@page` 讀回來的，沒有第二份寫死的數字。
改列印樣式時要記得：**新增的頂層區塊也要加進那條 `break-inside:avoid` 清單**，
否則它會跨頁，估算就會跟實際差開。

第一張如果是奇數頁（例如下肢 3），程式會在兩張之間**自動補一頁白**，
上面印一行說明。不補的話雙面列印會把上肢那張印在下肢那張的背面，
「一張紙雙面」就散了。Chrome 不支援 `break-before:recto`／`right`（實測不補頁），
所以只能自己算、自己插。

列印時要在瀏覽器設定勾雙面、把頁首頁尾關掉。

## 分享縮圖

`og.png` 由 `OG圖-原始檔.html` 截圖而來，版面沿用 exercise-sheet 那張：
左邊標題與七個層級晶片（晶片區寬度刻意收到 480px，讓它斷成 4＋3＝下肢四級、上肢三級），
右邊是一張單張的局部。**這套單張目前全是文字，所以縮圖就老實呈現文字的樣子**
——編號、劑量、紅框，不要假裝有示意圖。

```bash
cd tools/stroke-sheet
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=1 --window-size=1200,630 \
  --virtual-time-budget=8000 \
  --screenshot=/tmp/og-stroke-raw.png "file://$PWD/OG圖-原始檔.html"
python3 -c "
from PIL import Image
Image.open('/tmp/og-stroke-raw.png').convert('RGB').quantize(colors=64, dither=Image.NONE).save(
    '../../public/stroke-sheet/og.png', optimize=True, compress_level=9)"
```

**網址若要改**：`public/stroke-sheet/index.html` 開頭有四處絕對網址要一起改
（canonical、og:url、og:image、twitter:image），OG 原始檔頁尾那行網址也要改。

## 還沒做的

- **示意圖**：七張目前全是文字。神經動作比骨科難畫——轉位、患側保護、輪椅姿勢
  都涉及兩個身體部位的相對關係。建議先出文字版用一陣子，圖分批補。
- **動作影片與 QR**：決定先不留版面位置，等影片庫有東西再說。
- **替代動作**：主動作有禁忌時只能整項不做，沒有替代版。等實際用過再看需不需要。
