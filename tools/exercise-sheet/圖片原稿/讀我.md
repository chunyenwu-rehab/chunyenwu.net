# 圖片原稿

這裡放的是示意圖的 **1536×1024 PNG 原稿**（約 1.5 MB／張），檔名＝`exercises.js` 裡的動作 id。
單張產生器實際讀的不是這裡，而是壓過的 `public/exercise-sheet/assets/img/`（1200px，列印用）
與 `assets/thumb/`（480px，瀏覽用）。

**原稿不進版控**（見 repo 根目錄 `.gitignore`）：145 MB 的 PNG 進 git 之後每次 CI checkout 都要拉，
而且每改一張圖就永久多一份。網站要的壓縮檔有進版控，原稿只在這台機器上，請確認有被備份到。

## 改圖或加圖

1. 把新的 PNG 放進本資料夾，檔名用動作 id，例如 `k_slr.png`。
2. 執行 `./產生圖片.sh k_slr`（不帶參數＝全部重轉）；輸出會直接寫進 `public/exercise-sheet/assets/`。
3. 若是新動作，在 `public/exercise-sheet/exercises.js` 該筆加上 `img:'k_slr'`。
4. commit＋push，GitHub Actions 會自動部署。
