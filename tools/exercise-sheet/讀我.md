# 居家運動單張產生器｜工作檔

網站上的位置：<https://chunyenwu.net/exercise-sheet/>

## 檔案在哪

**程式本體只有一份**，就在 `public/exercise-sheet/`——Astro 的 `public/` 是原樣複製，
所以那個資料夾同時是原始碼也是部署內容，改完 push 就上線，不需要再同步到別的地方。

```
public/exercise-sheet/
  index.html        介面、版面、列印樣式
  exercises.js      動作庫（79 個動作、7 個主題共 27 階段）
  og.png            分享縮圖 1200×630
  assets/img/       示意圖 1200px，列印與預覽用
  assets/thumb/     示意圖 480px，動作庫瀏覽用
```

本資料夾放的是**不會部署出去的工作檔**：

```
tools/exercise-sheet/
  圖片原稿/           1536×1024 PNG 主檔（不進版控，見下）
    產生圖片.sh       由主檔壓出上面那兩種尺寸
  圖片檢查/           圖文一致性的逐張比對紀錄
  進階建議撰寫紀錄.md  「進步了怎麼調整」欄位的撰寫原則與逐條理由
  OG圖-原始檔.html    分享縮圖的原始檔
```

## 圖片原稿不進版控

`圖片原稿/*.png`（79 張、約 145MB）和 `圖片檢查/待整理圖片/` 在 `.gitignore` 裡。
理由是部署工作流用 `fetch-depth: 0`，進版控的話每次建置都要拉這 145MB，
而且每重畫一張圖就會在歷史裡永久多一份。

**代價是這些主檔只存在這台機器上**，請確認有被 Time Machine 之類的備份涵蓋。
網站實際要用的壓縮檔有進版控，所以就算主檔遺失，線上的東西不會消失，
只是之後沒辦法重新裁切或改壓縮參數。

## 常見工作

**改動作內容或版面**：直接改 `public/exercise-sheet/` 底下的檔案，commit＋push。

**換一張示意圖**：

```bash
# 1. 新的 PNG 放進 圖片原稿/，檔名用動作 id
# 2. 壓出兩種尺寸（會直接寫進 public/exercise-sheet/assets/）
cd tools/exercise-sheet/圖片原稿 && ./產生圖片.sh k_slr
# 3. 新動作的話，在 public/exercise-sheet/exercises.js 那筆加上 img:'k_slr'
```

**重做分享縮圖**：

```bash
cd tools/exercise-sheet
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=1 --window-size=1200,630 \
  --virtual-time-budget=8000 \
  --screenshot=/tmp/og-raw.png "file://$PWD/OG圖-原始檔.html"
python3 -c "
from PIL import Image
Image.open('/tmp/og-raw.png').convert('RGB').quantize(colors=64, dither=Image.NONE).save(
    '../../public/exercise-sheet/og.png', optimize=True, compress_level=9)"
```

圖上刻意不寫動作數量，動作庫擴充不必重做圖。

**網址若要改**：`public/exercise-sheet/index.html` 開頭有四處絕對網址要一起改
（canonical、og:url、og:image、twitter:image），OG 原始檔頁尾那行網址也要改。
